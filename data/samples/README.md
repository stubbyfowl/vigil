# Sample import file

`osdr_style_sample.csv` is invented. It is not real data and it did not come from NASA. It only shows the shape of a long table with a subject, a timepoint, a measure, a value and a unit.

The project rule is to use no real people's data, so the importer was tested on this file only. It has not been run on a file downloaded from the NASA Open Science Data Repository.

Timepoints can be plain numbers, or the launch-relative labels `L-92` (before launch), `FD3` (flight day) and `R+1` (after return).
